# Weather and Climate Data Analysis

### **[Arotake](https://github.com/jankazil/Arotake)**  
  Command-line tool and application programming interface (API) that automates evaluating:
  - [NOAA High-Resolution Rapid Refresh (HRRR)](https://rapidrefresh.noaa.gov/hrrr/) surface forecasts
  
  against observational time series:
  
  - [Local Climatological Data version 2 (LCD v2)](https://www.ncei.noaa.gov/access/search/data-search/local-climatological-data-v2)
  - [Integrated Surface Database Lite (ISD-Lite)](https://www.ncei.noaa.gov/access/search/data-search/global-hourly)
  
### **[hrrr-data](https://github.com/jankazil/hrrr-data)**  
  Command-line tool and API that automates accessing, downloading, and processing NOAA High-Resolution Rapid Refresh (HRRR) forecast data from NOAA’s public AWS S3 bucket.

###  **[madis-data](https://github.com/jankazil/madis-data)**  
  Command-line tool and API to automatically create analysis-ready UTC full-hour [MADIS Mesonet](https://madis.ncep.noaa.gov/madis_mesonet.shtml) and [MADIS Metar](https://madis.ncep.noaa.gov/madis_metar.shtml) observation datasets for arbitrary date ranges, for U.S. states and RTO/ISO regions, as netCDF files.
  
###  **[lcd-v2-data](https://github.com/jankazil/lcd-v2-data)**  
  Command-line tool and API to automatically create analysis-ready UTC full-hour Local Climatological Data version 2 ([LCD v2](https://www.ncei.noaa.gov/access/search/data-search/local-climatological-data-v2)) observation datasets for arbitrary date ranges, for U.S. states and RTO/ISO regions, as netCDF files.

###  **[isd-lite-data](https://github.com/jankazil/isd-lite-data)**  
  Command-line tool and API to automatically create analysis-ready UTC full-hour Integrated Surface Database Lite ([ISD-Lite](https://www.ncei.noaa.gov/access/search/data-search/global-hourly)) observation datasets for arbitrary date ranges, for individual countries, U.S. states and RTO/ISO regions, and individual stations, as netCDF files.
